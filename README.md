
# Python Week 2 - Simple Bill Calculator

## Description
This project is a simple Python program that asks the user
for the price of one item and the quantity they want.
It calculates the total cost and displays a friendly summary
using an f-string.

## Concepts Used
- User input with input()
- Type conversion using float() and int()
- Multiplication and arithmetic
- F-strings for formatted output

## How to Run
1. Install Python.
2. Open a terminal in the project folder.
3. Run the command:

   python main.py

## Example Output
3 items at 50.00 each = 150.00
